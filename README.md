# Capsule Wardrobe

The rebuild lives in `app/`. The original `capsule_frontend/` and `capsule_backend/` prototype is preserved for reference.

## First working release

A mobile-friendly, private wardrobe with ChatGPT sign-in, persistent original photo uploads, batch progress/retries, editable garment metadata, search, category filters, favorites, laundry/archive states, and photo deletion.

This release does **not** implement AI tagging, background removal, outfit generation, preference learning, gap analysis, or shopping. Garments start as Unsorted / Unknown until edited. Example clothing in the empty state is clearly labeled and never added to personal wardrobes.

See [app/README.md](app/README.md) for setup, architecture, validation, and the next milestones.
